# Forge Calendar portal

Docs and live demos for [`@forgedevstack/calendar`](https://www.npmjs.com/package/@forgedevstack/calendar).

Site: [https://forgecalendar.com](https://forgecalendar.com)

```bash
npm install
npm run dev
```

Uses Bear UI, Forge Compass, and `@forgedevstack/calendar@1.0.0`. Local Vite aliases `../calendar/src`. Vercel deploys `main` only (same ignore pattern as Ink portal).
